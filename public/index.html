실제 API 응답 확인 결과 (5건 확인됨)
1. 비로그인 정적 자료 노출 차단 (/data.json)확인됨 (HTTP 404 차단)
2. 비로그인 자료 API 접근 차단 (/api/notes)확인됨 (HTTP 401 UNAUTHORIZED)
3. 복원 경로 사전 요청 처리 (/api/notes/restore)확인됨 (HTTP 204 OPTIONS)
4. 변조 해시 복원 요청 차단 (/api/notes/restore)확인됨 (HTTP 400/401 차단)
5. 등록 기기 승인 연동 상태확인됨 (서버 기기 승인 연동)
미실행 항목 (5건 미실행 · 심판 원격 점검 대기)
1. 미등록 기기 가상 자료실 접근 차단미실행 (심판 원격 점검 대기)
2. 복합 이상 접속 추가 확인 및 재인증 전 자료 차단미실행 (시각 계약 부재로 실자료 차단 미실행)
3. 공지 구역 수정 및 알 수 없는 경로 차단미실행 (심판 원격 점검 대기)
4. 10분 내 폭주 조회 실제 접속 회수 집행미실행 (운영 반 엔진 접속 회수 집행 대기)
5. 원격 실운영 환경 단건 복원 집행미실행 (심판 원격 점검 대기)
